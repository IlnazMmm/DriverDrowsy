# Контракт v1

`schemas/feature_window.schema.json` — нормативный machine-readable контракт.
Major `1` фиксирует семантику: native units, шесть обязательных ключей и
`null + reason` для неизвестного. `0` допустим только для наблюдавшейся частоты
событий, но не заменяет пропуск. Quality разделена по eye/mouth/gaze.

PERCLOS интегрируется по левым интервалам реальных timestamps. Интервалы через
gap и неизвестное состояние исключаются из знаменателя. Это исключает
экстраполяцию через разрыв. Повтор/регресс времени — ошибка. Событие на границе,
gap или missing помечается censored и не включается в частоту завершённых событий.
Prolonged closure остаётся в PERCLOS и хранится отдельным событием.

Диапазон sensitivity — результат возмущения параметров, не FOU и не доверительный
интервал. Нормализация допускается только параметрами train split.
